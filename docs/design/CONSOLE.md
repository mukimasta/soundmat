# Console

控制台是在浏览器里打开的网页，用来查看 SoundMat 的状态、控制它，以及在开发机上开发。它有两类使用者：展出、演示和拍摄时，现场的人用手机确认装置正常、切换编排、开始录制；开发时，开发者在电脑上用虚拟垫子开发声音、查看问题。页面首先按手机屏幕设计，在电脑上自然展开。视觉与交互以设计稿 `SoundMat 控制台.html` 为准（深色界面，五个画面：垫面 · 京都岚山、垫面 · Lo-Fi、看板、看板 · 异常、编排）。

控制台最重要的作用是让人一眼看出装置能不能正常演奏，其次才是控制。控制项保持少而安全，任何修改立即生效并被保存。

## 页面结构

打开控制台首先看到垫面：它就是装置此刻在做什么的直接画面。底部固定三个入口：左边**看板**，中间醒目的**录制**按钮，右边**菜单**。菜单里是**已录制**和**设置**；点垫面下方的当前编排卡片打开**编排**。编排、菜单、已录制和设置都以从底部升起的面板出现，点面板外的区域、关闭按钮或按 Esc 键关掉即回到垫面；看板是单独的一页，左上角返回垫面。

任何一项状态需要注意或异常时，垫面页顶部出现一条提示，直接写出原因（例如"声音：合成器服务没有使用 USB 声卡"），点它进入看板；底部看板入口上同时出现一个对应颜色的小点。所以停在垫面上也不会错过问题。

## 垫面

顶部左侧是 SoundMat 标识和装置当前所在的网络与地址，右侧是垫面上的石头数和实测传感帧率。

中间是垫面实时图：224 个区域按压力深浅着色，每环有自己的代表色；被判断为有石头的区域上画出一颗石头；外圈是灯环的实时预览。录制倒计时的数字和"打板"也叠在垫面中央显示。

垫面下方是一行当前模式的状态和一组声音电平。状态行由模式给出，例如 Ambient 显示"每环一层 · 左右两只音箱"和总输出电平，Jam 显示当前段落与进度（"第 3 段 C · 0:44 / 2:08"）和 Lo-Fi 强度，空闲和曲终时提示怎样开始。

电平条每一层声音一根，名字只写一次，写在条下面，正在发声的名字更亮。电平条不分左右声道：声音的方位已经由垫面上石头的位置表达，这里只回答"这一层有多响"。电平条分成两组，组之间只靠间距分开，不加标题：

1. **背景**：不靠放石头、自己在走的部分，例如 Lo-Fi 的和声铺底和鼓。
2. **石头**：由放置的石头触发的部分，通常每个发声的环一根，例如京都岚山的"低音、和声、竹林……"。

显示哪些层、怎样分组由编排决定（`implementation/ARRANGEMENTS.md`「电平条」）；控制环不发声，不占位置。

最下面是当前编排卡片：名称、模式和状态（演奏中、空闲、曲终、正在切换到某编排及进度），点开即是编排面板。

在虚拟垫子模式下，这个页面就是虚拟垫子：点一个区域放下一颗石头，再点一次拿起；顶部右侧换成"清空"按钮，垫面外圈有一圈虚线提示可以点按。

## 看板

最上方是总体结论（一切正常、需要注意、异常），有问题时下面一句话写出原因；再下面是三个状态指示：**声音**、**垫子**、**网络**，各自用正常、需要注意、异常三种状态表示，无法得知时显示"未知"。

下方按组展开详细信息，声音一组排在最前：

1. **声音**：左右声道的输出电平表；合成器服务的运算负载（仪表加最近 1 分钟的曲线，红线是峰值上限 85%）；卡顿次数、在响声部数与上限、采样率、声道数、缓冲设置、音色与声音素材是否加载完整（缺失的逐个列出）；合成器服务实际使用的输出设备。与期望不一致的项用需要注意或异常的颜色标出，并写出期望值。这里提供逐个声道的测试音，按下后对应音箱发声，用来确认每只音箱的位置。
2. **垫子**：实测传感帧率及最近 60 秒的曲线、输入来源（压力垫控制器或虚拟垫子）、控制器连接情况、校验错误数。
3. **节奏**：每条链路的实测帧率与期望值并排：传感、垫面解读、声音化节拍、灯光引擎、写给控制器的灯光、推送到控制台的垫面与灯环，以及正在看看板的这台设备自己的显示帧率；低于期望的标出来。垫面和灯环只在有变化时推送，静止时为 0 属于正常。下面是最近 1 分钟最大的节拍延迟（以及超过迟到容忍度的次数）、迟到丢弃，以及声部让位和因预算放弃的次数。
4. **网络**：连接类型（手机热点、自建热点、外部网络、有线网络）和连接名、地址、Tailscale 状态；自建热点开着时显示大约连着几台设备。
5. **机器**：温度与是否降频、内存、剩余空间和按当前声道与分轨设置还能录多少时间、机器和主机程序各自已运行多久、主机程序被自动重启过几次、当前运行的程序版本。
6. **最近的警告和错误**。

## 编排

列出所有编排，每项显示名称、模式和简短说明；正在演奏的一项有明显标记，引用的素材有缺失时在该项上提示。点选即切换，新旧编排之间交叉淡化，切换过程中显示进度。面板下方调整总音量。

## 录制

录制按钮在底部中间，按下后开始录制并进入倒计时（行为见 `RECORDING.md`）：按钮上显示 3、2、1，垫面中央同步显示大号数字，倒计时结束显示"打板"；录制中按钮变为停止，下方显示已录时长。菜单里的"已录制"列出已有的录制，每项显示时间、编排、时长，可以下载。

## 设置

调整音箱布局与垫面朝向（附示意图）、默认编排、录制选项（是否录制分轨）；显示声音素材库和录音保存位置。修改立即生效并自动保存。校准与对齐参数（阈值、去抖时间、旋转偏移、灯带偏移、声部预算等）来自仓库里的配置，在"配置 · 只读"一栏显示，不能修改。

## 全局行为

使用虚拟垫子时，所有页面顶部都有明显的"虚拟垫子"标识，避免把开发状态误当成真实装置。

控制台与装置的连接断开时，页面明确显示"已断开"，不继续显示过时的数据；恢复后自动重新连接。

控制台不设登录。能连上装置所在局域网（手机热点、装置自建的热点）或通过 Tailscale 访问的人才能打开控制台，访问范围由网络本身限定。

开放时段、音量上限和编排参数现场调整是预留功能，当前不出现在页面上。
