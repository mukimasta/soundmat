# Console

控制台是在浏览器里打开的网页，用来查看 SoundMat 的状态、控制它，以及在开发机上开发。它有两类使用者：展出、演示和拍摄时，现场的人用手机确认装置正常、切换编排、开始录制；开发时，开发者在电脑上用虚拟垫子开发声音、查看问题。页面首先按手机屏幕设计，在电脑上自然展开。

控制台最重要的作用是让人一眼看出装置能不能正常演奏，其次才是控制。控制项保持少而安全，任何修改立即生效并被保存。

## 页面

### 看板

打开控制台首先看到看板。最上方是三个状态指示：**声音**、**垫子**、**网络**，各自用正常、需要注意、异常三种状态表示，旁边显示当前编排和是否正在录制。任何一项异常时，指示旁直接写出原因，例如"合成器服务没有使用 USB 声卡"或"控制器未连接"。

下方按组展开详细信息，声音一组排在最前：

1. **声音**：音频服务、USB 声卡、合成器服务是否正常；合成器服务实际使用的输出设备、采样率、声道数和缓冲设置，与期望不一致的项明显标出；音色和声音素材是否加载完整，缺失的逐个列出；卡顿次数、运算负载、在响的声部数、每个声道的输出电平。这里提供逐个声道的测试音，按下后对应音箱发声，用来确认每只音箱的位置。
2. **垫子**：控制器是否连接、实测传感帧率（也是灯光的实际刷新率）、校验错误数。
3. **机器**：温度与是否降频、内存、剩余空间、已运行时长。
4. **网络**：当前连接的网络、地址、Tailscale 状态。
5. **最近的警告和错误**。

### 垫面

实时显示垫面：224 个区域按压力深浅着色，被判断为有石头的区域有明显标记，外圈是灯环的实时预览。页面上显示实测传感帧率。

在虚拟垫子模式下，这个页面就是虚拟垫子：点一个区域放下一颗石头，再点一次拿起；提供一键清空。

### 编排

列出所有编排，每项显示名称、模式和简短说明；引用的素材有缺失时在该项上提示。点选即切换，新旧编排之间交叉淡化。这里也调整总音量。

### 录制

一个醒目的录制按钮。按下后开始录制并进入倒计时（行为见 `RECORDING.md`），录制中显示已录时长和剩余空间，按钮变为停止。下方列出已有的录制，每项显示时间、编排、时长，可以下载。

### 设置

手动调整校准参数（阈值、去抖时间、旋转偏移等）、音箱布局与垫面朝向、灯珠数量与对齐偏移、默认编排、声音化节拍频率、录制选项。网络和系统信息在这里只读显示。

## 全局行为

使用虚拟垫子时，所有页面顶部都有明显的"虚拟垫子"标识，避免把开发状态误当成真实装置。

控制台与装置的连接断开时，页面明确显示"已断开"，不继续显示过时的数据；恢复后自动重新连接。

控制台不设登录。能连上装置所在局域网（手机热点、装置自建的热点）或通过 Tailscale 访问的人才能打开控制台，访问范围由网络本身限定。

开放时段、音量上限和编排参数现场调整是预留功能，当前不出现在页面上。
