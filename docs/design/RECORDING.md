# Recording

录制用来留下 SoundMat 演奏时干净的声音，供后期制作使用，并且能和另外拍摄的视频准确对齐。它同时记下垫面上发生了什么，方便以后制作同步的可视化或重放一次演奏。

### 开始与结束

在控制台按下录制后，灯环和控制台进入 3、2、1 的倒计时，每秒一步：灯环分成三段，开始时三段全亮，之后每秒熄灭一段。倒计时结束的瞬间，灯环整圈全亮闪一下，同时音箱在现场发出一声短促的提示音。这一下就是打板，录音正好从这一刻开始：倒计时那几秒不录，提示音只在现场响、给摄像机录到，不进录音，所以录下的文件开头就是干净的演奏。倒计时期间音乐照常进行，不被打断。

录制持续到在控制台按下停止为止。录制期间可以照常切换编排，录音不中断。控制台显示正在录制、已录时长和剩余空间。

开始前检查存储空间，不足以录制一段合理时长时拒绝开始并说明原因。录制中空间即将用尽时自动停止，已经录下的内容完整保留。

### 产出

每次录制产生一个独立的文件夹，以开始时间和编排名称命名，包含：

1. **总输出**：送往音箱的最终声音，声道数与当前音箱布局一致，无损格式。
2. **分轨**：每个环一轨，模式另外声明的分组（例如 Jam 的和声、鼓）各一轨，加上共用效果（如混响）的回送一轨，后期可以单独调整各层的平衡。录制中切换编排时，新旧编排的声音一起进入同一组分轨。分轨取自整体处理之前：作用于整个模式的效果（例如 Jam 的 Lo-Fi）只在总输出里，所以分轨相加接近但不完全等于总输出。分轨可以在设置里关闭。
3. **会话数据**：压力图、放下与拿起事件、声音意图和灯光意图，按时间顺序记录。
4. **录制信息**：开始（即打板）的准确日期时间、编排与模式、开始时的设置。

录下的文件可以在控制台下载（整个文件夹打包成一个 zip），也可以由开发机同步取回。

### 与视频对齐

日常对齐依靠剪辑软件按波形自动同步：拍摄设备自带的麦克风录到的现场声音，足以让常见剪辑软件把干净的录音自动对上。

自动同步失败时使用打板：在视频里找到灯环整圈闪亮的那一帧（摄像机的麦克风同时录到了提示音），把录音文件的开头对到这一刻，可以精确到一帧以内。提示音每次都相同、短促、容易辨认。

录制信息里的开始时间用于在素材很多时粗略找到对应的片段。
