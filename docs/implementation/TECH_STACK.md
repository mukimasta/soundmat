# Tech Stack

本文记录主机程序及其运行环境当前采用的技术，以及选择它们的理由。模块划分与运行机制见 `ARCHITECTURE.md` 和 `system_design/`。

## 运行平台

| 环境 | 选择 |
|---|---|
| 装置 | Raspberry Pi 5，Raspberry Pi OS Lite（64 位，无桌面） |
| 开发 | macOS，同一套主机程序加虚拟垫子 |
| 控制器 | ESP32，固件与串口协议见系列文档第 7 篇 |

无桌面系统把资源留给音频。所有交互通过控制台和 SSH 完成。

## 主机程序

主机程序用 Python 编写，版本 3.12 或更新，由 uv 管理解释器和依赖，不依赖系统自带的 Python。压力图等数值计算用 NumPy。

并发按节奏划分：设备读取、声音化节拍、灯光刷新各占一个线程，控制接口运行在一个 asyncio 事件循环里。线程之间只通过两种线程安全的容器交换数据：保存最新值的容器，和可一次取走全部内容的事件队列，与 `system_design/DATA_MODEL.md` 中的传递方式一一对应。这样的负载在 Pi 5 上远低于单核能力，不需要多进程。

串口通信用 pyserial，沿用现有固件协议：921600 波特，ASCII 文本帧（S 帧上行、L 帧下行），带 XOR 校验。

## 合成器服务

合成器服务是 SuperCollider 的 scsynth，在树莓派上作为独立的系统服务运行，不由主机程序启动（开发机上没有在运行的 scsynth 时，主机程序自己启动一个，方便一条命令运行）。这样主机程序重启时声音引擎可以重新对账而不必重启音频，scsynth 异常退出时由系统守护重启。

音色用 SuperCollider 语言编写，在开发机上用 sclang 编译成 SynthDef 文件，随部署一起分发；树莓派上只运行 scsynth。

主机程序通过 python-osc 向 scsynth 发送 OSC 消息。带时间戳的指令使用 OSC bundle，时间戳取自系统时钟；主机程序和 scsynth 在同一台机器上，共用同一个时钟。

录制由 scsynth 在内部完成：总输出和各分轨写成多声道无损音频文件，与系统采样率一致。

## 音频服务

树莓派上使用 JACK2（jackd），通过 ALSA 驱动 USB 声卡，scsynth 作为 JACK 客户端。装置只有 scsynth 一个音频程序，不需要桌面音频系统的混音和路由；JACK2 直接、可控，也是之前在 Pi 3B 上调过参数的方案。JACK 的缓冲设置先沿用之前验证过的值，再按 Pi 5 的实际表现下调以降低延迟。

开发机上 scsynth 直接使用 macOS 的 CoreAudio。

## 控制接口与控制台

控制接口用 FastAPI 和 uvicorn。状态通过一条 WebSocket 推送：连接时先发完整快照，之后只发生了变化的部分；命令和设置修改走 HTTP。

控制台是独立的前端工程，用 React、Vite 和 TypeScript，与浏览器版原型（`SoundMat/web/soundmat/`）保持一致。构建出的静态文件由控制接口直接提供，树莓派上不需要单独的网页服务器。

## 存储

| 内容 | 格式 |
|---|---|
| 配置 | 仓库里的 `config/soundmat.toml`，启动时读取；压力相关数值沿用 ADC 原始读数（满量程 4095），载入时换算成归一化压力 |
| 设置 | 一个 JSON 文件，写入时先写临时文件再整体替换，避免断电损坏 |
| 编排 | TOML，每个编排一个文件夹 |
| 会话数据 | JSON Lines，每行一条带时间的记录 |
| 日志 | systemd journal；控制台显示的最近记录保存在内存中 |

## 系统服务与部署

| 职责 | 采用 |
|---|---|
| 开机与守护 | systemd：jackd、scsynth、主机程序各一个服务，按顺序启动，异常退出自动重启 |
| 联网 | NetworkManager：按优先级保存手机热点、UW MPSK 等连接，超时后启用自建热点 |
| 远程访问 | Tailscale |
| 局域网名称 | avahi，提供 `.local` 名称 |
| 部署 | 开发机通过 SSH（局域网或 Tailscale）用 rsync 推送程序和配置，安装脚本负责系统服务；声音素材从开发机的 `SoundMat/sound/` 单独同步 |

所有系统服务的配置文件都放在仓库的 `system/` 目录，部署时安装到对应位置。

## 测试

测试用 pytest。声音引擎有一个不发声、只记录指令的实现，用于在没有合成器服务的环境里验证对账和调度。
