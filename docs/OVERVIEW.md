# Overview

SoundMat 主机系统是 SoundMat 装置运行在树莓派上的大脑：它接收压力垫的读数，理解垫面上的石头，实时生成声音和灯光，并提供一个手机和电脑都能打开的控制台。它面向两类人：在展出、演示和拍摄现场照看装置的人，以及打磨声音、维护系统的开发者。当前正在按 `ARCHITECTURE.md` 描述的新架构重写；2026 年 6 月的第一版实现仍在仓库中。

**解决什么问题。** 作为公共艺术装置，SoundMat 常常放在无人看管的空间里长时间运行。现场的人不懂代码，却需要知道它是否正常，出问题时知道问题在哪。它的声音又需要反复打磨，开发者不可能每次都搬着垫子和树莓派去试听。第一版程序能演奏，但结构纠缠、状态不透明、部署靠手工配置，几个月后连作者也难以接着做下去。

**交付物。**

1. 主机程序：感知垫面，用不同的模式和编排生成声音与灯光，录制演奏，监测整台机器的状态。
2. 网页控制台：看板、垫面与虚拟垫子、编排切换、录制、设置。
3. 树莓派的系统配置与部署：开机自启与守护、联网与 Tailscale、音频服务，可以从仓库完整重建。
4. 开发环境：在 Mac 上用虚拟垫子运行同一套程序，听到和装置上一样的声音。

**用户场景。** 展出前一晚，开发者在家打开 Mac 上的虚拟垫子，调整《京都岚山》的编排，点几下区域就听到装置上会发出的声音，满意后通过 Tailscale 部署到树莓派。第二天到了现场，接上电源和音箱，一分多钟后装置自己进入默认编排，灯环开始呼吸。现场的人打开手机热点，在控制台的看板上看到声音、垫子、网络三项都正常，按下录制，灯环倒数三、二、一后闪亮，摄影机同时开拍。中途控制器的线被碰松，声音和灯光照常继续，看板把"垫子"标成需要注意；线插回去之后自动恢复。

SoundMat 主机系统希望让装置在任何场地都能插电即用、出了问题一眼看清，也让声音的打磨始终轻快。
